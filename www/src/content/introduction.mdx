# Introduction

MAF is a framework for building and deploying realtime applications.

By abstracting away common realtime primitives like connections, state,
and channels, MAF makes creating applications a breeze.

## Comparisons

Compared to frameworks like Firebase, Supabase, and Liveblocks, MAF
takes a **server-centric approach**. Instead of writing client-side methods to
mutate realtime data, apps made with MAF are governed by a _server_ that
authorizes requests.
